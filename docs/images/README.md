## 截图规范

**尺寸**
- 宽度 1400~2000px 最合适（GitHub 内容区约 880px，2 倍图清晰）
- 高度按内容截，不要超过 1200px（否则 README 里会很长）
- **不要用整屏截图**，把浏览器地址栏、书签栏、任务栏裁掉

**内容**
- 用 `npm run samples` 生成的**合成数据**，不要用真实账务数据
  （样例登录的是「示例科技有限公司」，很适合公开）
- 浏览器缩放调到 100%，保证文字清晰可读
- 深浅色模式下都用浅色主题，GitHub 默认浅色

**体积**
- 每张控制在 **400KB 以内**
- PNG 用 [TinyPNG](https://tinypng.com/) 或 `pngquant` 压缩一下
- 避免超过 1MB，否则仓库克隆会变慢

**命名**
- 用 `序号-中文描述.png`，序号决定 README 里的排列顺序
- 不要用空格，用 `-` 连接

## 截图命令参考

如果要在 Windows 上自动化截图（需要 Playwright 或 Puppeteer）：

```bash
# 先启动服务
npm run web

# 另开一个终端，用你习惯的工具截
# 建议截图前把窗口设置为 1600x1000
```

手动截图也可以，Windows 用 `Win + Shift + S` 框选即可。

## 截好后

把 PNG 放进本目录，README 里对应的引用就会自动生效：

```markdown
![上传单据](docs/images/01-上传单据.png)
```

如果文件名和上表不一致，记得同步修改 `README.md` 里的引用路径。
