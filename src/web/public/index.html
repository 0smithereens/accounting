    2. 处理结果

    包含 记账凭证 / 科目汇总表 / 单据台账 / 问题与待办 / 导入模板 / 处理说明

    使用提示

    • 先看「问题与待办」。错误级别的问题必须处理，否则凭证可能不符合你的实际业务。
    • 同一笔业务不要重复导入。系统会自动识别银行代发工资与工资表的重复，但其它重复需你自行判断。
    • 科目与规则都可配置。修改 config/mappings/*.yaml 后刷新本页重新生成即可，不用改代码。
    • 生成的凭证是草稿。请务必人工复核后再导入财务软件，尤其是走「待处理财产损溢」的分录。
    • 期初余额不在本工具范围内。银行对账单的期初余额需在金蝶/用友中录入，否则银行存款科目余额会偏移。
